 
# PromptGrow

**思考の「種」を、AIへの「最強のプロンプト」に育てる。**

日常の閃きをメモで終わらせず、再利用可能なプロンプトテンプレートとして蓄積・合成するPWAアプリ。プラットフォームの規約に縛られず、ホーム画面から即起動。起動からコピーまで3秒。

---

## なぜ作ったか

AIに「いい質問」をするのは難しい。毎回ゼロから考えるのは非効率で、せっかくの閃きも単なるメモで埋もれていく。

PromptGrowは「自分だけの型」を育てるためのツールだ。アイデアをストックし、テンプレートと合成し、ワンタップでコピーする。思考のバックアップとして、自己分析のログとして機能する。

---

## 機能

### STOCK — アイデアを貯める
- タイトル・本文・タグでアイデアを保存
- タグによる分類・視認性の確保
- オフライン環境でも動作（Service Worker キャッシュ）

### COMPOSE — 合成する
- ユーザーが定義した「前提条件テンプレート」を選択
- 生データ（今日の閃き・メモ）を入力
- プレビューをリアルタイム確認
- ワンタップでクリップボードへコピー → AIアプリへ貼り付け

### LOG — 俯瞰する
- 月次のアイデア数・タグ頻度をグラフ化
- 自分の思考トレンドを可視化
- テンプレートの一覧管理

---

## テンプレートの書き方

テンプレート本文に `{{raw}}` と書くと、COMPOSE画面で入力した生データがその位置に挿入される。

```
あなたは優秀な編集者です。以下の文章を読み手の視点でレビューしてください。

目的：
読み手：

文章：
{{raw}}
```

`{{raw}}` を書かない場合は、本文の末尾に自動で追記される。

## インストール・デプロイ

### ローカルで試す

```bash
git clone https://github.com/yourname/promptgrow.git
cd promptgrow

# 任意のローカルサーバーで起動（file://では Service Worker が動作しない）
npx serve .
# または
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開く。

### GitHub Pages にデプロイ（推奨）

```
1. このリポジトリを fork またはクローン
2. GitHub の Settings → Pages → Branch: main を有効化
3. https://yourname.github.io/promptgrow/ にアクセス
4. ブラウザの「ホーム画面に追加」でPWAとしてインストール
```

> **注意**: PWA の Service Worker は HTTPS 環境でのみ動作する。GitHub Pages は自動で HTTPS が有効になるため推奨。

## 設計の指針

- **ユーザー主導**: 自動整形・AI自動補完は行わない。あくまで自分が設定した「型」に忠実に動く
- **スピード重視**: 起動からコピーまで3秒を目標とした最小UI
- **脱・プラットフォーム依存**: App Store不要。ブラウザからそのままインストール
- **データは自分のもの**: サーバーへの送信なし。すべてデバイス内のIndexedDBに保存
